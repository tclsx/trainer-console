训练助手 · 快速开始
========================================

第 1 步   双击「1-安装.bat」
          按提示填 3 项：平台地址、学号、密码。
          （电脑上需要先有 Python 3.10+，没有的话脚本会告诉你去哪下载）

第 2 步   双击「2-启动控制台.bat」
          浏览器自动打开 http://127.0.0.1:8791/

第 3 步   在控制台右侧「LLM 设置」填入你自己的 API key 并启用
          （不填也能打开控制台，但点「开始」不会自动解题）

常见问题一句话：
· 连不上服务器 → 平台地址填错，或你不在能访问该平台的内网/VPN 里。
· 点「开始」变成「未完成」 → LLM 没启用，见教程第 4 节。
· 想把软件发给别人 → 发 zip 包，不要发你正在用的整个文件夹（里面有你的账号密码）。
